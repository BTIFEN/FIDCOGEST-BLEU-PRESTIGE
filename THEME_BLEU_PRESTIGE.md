# FIDCOGEST — thème Bleu Prestige

Palette : bleu nuit `#142B45`, bleu ardoise `#47647C`, or discret `#B79661`, blanc cassé `#F7F8F6`, anthracite `#26343E`.

La personnalisation graphique est isolée dans `src/styles/fidcogest-prestige.css`. La classe `fid-prestige` est appliquée au conteneur principal (`src/App.tsx`). Les composants, routes et logiques fonctionnelles d’origine ont été conservés.

## Exécution

`npm install` puis `npm run dev` ; pour une version de production `npm run build`.

## Vérifications à effectuer avant publication

Vérifier sur l'environnement réel : affichage mobile, contraste des widgets et fenêtres modales, calculs, prise de rendez-vous, transfert de documents, intégration serveur, données fiscales et coordonnées.
