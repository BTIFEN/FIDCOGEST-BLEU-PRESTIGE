FIDCOGEST
Configuration du premier administrateur

Préparez votre accès en toute confidentialité

Aucune installation. Votre mot de passe et votre MFA sont préparés et chiffrés dans ce navigateur. Aucun formulaire n’est envoyé au serveur.

Cette page prépare un fichier chiffré. La création du compte nécessite ensuite son dépôt dans le répertoire privé de l’hébergement par une personne autorisée.

1. Sélectionnez la demande privée

Utilisez uniquement le fichier request.json récupéré dans le gestionnaire Hostinger authentifié du site concerné. Le fichier est lu sur votre appareil ; il n’est pas téléversé.

2. Choisissez vos identifiants

Au moins 16 caractères, avec une majuscule, une minuscule et un chiffre.

3. Configurez votre Authenticator

Sur votre téléphone, ajoutez un compte TOTP nommé FIDCOGEST avec la clé ci-dessous. Paramètres : 6 chiffres, 30 secondes, SHA1.

Cette clé est privée. Ne la photographiez pas et ne l’envoyez pas dans le chat.

Si le code change au moment de la saisie, attendez le suivant puis réessayez. Vérifiez que l’heure automatique est activée sur les deux appareils.

4. Conservez vos codes de récupération

Conservez ces dix codes dans votre coffre privé. Ils permettent de récupérer votre accès si vous perdez votre Authenticator.

5. Remettez uniquement le fichier chiffré

Télécharger enrollment.enc.json

  1. Téléversez uniquement ce fichier dans fidcogest_private/admin-bootstrap via le gestionnaire Hostinger authentifié.
  2. Réglez ses droits sur 0600 : lecture et écriture pour le propriétaire uniquement.
  3. Redémarrez ou redéployez l’application avant l’échéance indiquée.
  4. Vérifiez le message générique [Portal bootstrap] created, puis connectez-vous avec votre mot de passe et votre Authenticator.

Le fichier ne peut être lu qu’avec la clé privée du serveur. Ne le publiez pas. Après création et vérification du compte, retirez la variable d’amorçage temporaire.

La création réelle du compte et la validation de Google Drive restent à vérifier. Aucun document client ne doit être utilisé pour les essais.
